### Tecnologias Utilizadas

- Java Script
- Thunder Client
- XAMPP
- MariaDB / MySQL
- VS Code

### Instruções para testar
1 - Use os códigos no repositório acima, inicia o servidor no terminal (CMD ou NODE): 
- npm init -y
- npm i express cors
- npm install mysql
- npm run dev (após criar o server.js)

2 - Inicie uma nova página no Thunder Client, usando o link do servidor, e teste os códigos.
